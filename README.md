# Ultimate Murcia Property Sales

Official modern luxury real estate web application for Ultimate Murcia Property Sales (Costa Cálida, Spain).

## Architecture & Technology Stack
- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS (Mediterranean Luxury Palette)
- **Database & Auth:** Supabase PostgreSQL + Auth
- **Property MLS Feed:** Spanish Resales Online Web API connector (`/api/resales/sync` & `/api/resales/properties`)
- **Deployment:** Vercel Edge Network
